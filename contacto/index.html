InfoContrato lo hace una sola persona, Asier Fernández, desde Tarazona (Zaragoza). La forma de contactar es el correo electrónico: asierfernandezmotilva@gmail.com.

Escríbenos para

  • Avisar de un error en un texto, una cifra o una herramienta. Indica la página y qué has visto: cada aviso se revisa y, si procede, se corrige y se actualiza la fecha de revisión.
  • Proponer una mejora o un caso que las herramientas no contemplan.
  • Enlazar InfoContrato desde tu web, o colaborar si tienes una gestoría, una asociación o un medio. Tienes códigos para enlazarnos en Quiénes somos.

Lo que no podemos hacer

  • Asesorar tu caso concreto. InfoContrato es una web informativa, no una gestoría ni un despacho. Para eso, consulta con una gestoría o con un abogado.
  • Ver tus documentos. Las herramientas funcionan en tu navegador y no guardan lo que escribes, así que no podemos recuperar un documento ni consultarlo. No nos envíes datos personales de otras personas.

Cuándo respondemos

Intentamos responder en unos días. Los avisos de errores tienen prioridad.

Tus datos

Si nos escribes, usamos tu dirección de correo solo para responderte. Lo explicamos en la política de privacidad. Los datos del titular de la web están en el aviso legal.
